# Project – Deploy and Configure a Web App (Terraform + Ansible)

## Objective
Provision AWS infrastructure using Terraform and configure a simple Nginx web server using Ansible.  
Access to the private EC2 instance is secured using a bastion host and SSH key–based authentication generated by Terraform.

---

## Architecture Overview

- AWS VPC with public and private subnets
- Bastion host in a public subnet
- Application EC2 instance in a private subnet
- Security groups enforcing least-privilege access
- Terraform for infrastructure provisioning
- Ansible for configuration management

Traffic flow:
- SSH from local machine → Bastion host → Private EC2
- HTTP traffic → Private EC2 (via security group rules)

## Workflow

1. Terraform provisions:
   - Networking (VPC, subnets, routing)
   - Security groups
   - Bastion host
   - Private EC2 instance

2. Terraform outputs:
   - Bastion public IP
   - Private EC2 private IP
   - SSH key path

3. SSH access:
   - Local machine connects to bastion
   - Bastion connects to private EC2

4. Ansible:
   - Uses bastion as a jump host
   - Installs and configures Nginx on the private EC2 instance

---

## Prerequisites

- AWS account and credentials configured
- Terraform >= 1.5
- Ansible installed
- SSH client installed

---

## Usage

Provision infrastructure:
cd terraform
terraform init
terraform apply


Configure the server:
cd ansible
ansible-playbook playbooks/nginx.yml



---

## Security Notes

- Private EC2 instances are not exposed to the internet
- SSH access to bastion is restricted to your public IP
- SSH access to private EC2 is allowed only from the bastion security group
